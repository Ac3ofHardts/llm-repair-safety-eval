# Qualitative coding

- `coding_sheet.csv`: created by `make coding` (`analysis/code_export.py`). One row per **distinct**
  patch of interest, with heuristic labels. Fill in `code` and `notes` using `docs/codebook.md`.
  The exporter refuses to overwrite a sheet that already has codes.
- `coding_cases.md`: the same cases with diffs, for reading.
- `agreement.csv`: the 20 cases both authors coded independently, used to report inter-rater agreement.
